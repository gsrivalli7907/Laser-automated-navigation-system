# Laser-automated-navigation-system

This project integrates:
- Laser Detection
- Drawing Engine
- Gesture Control
- Voice Control
- Mouse Control
- Export (Image + PDF)

## Features
- Draw using laser pointer
- Control system using gestures and voice
- Move mouse using laser
- Save output as image or PDF

## 🎮 Controls

### ⌨️ Keyboard Controls
- `q` → Quit application  
- `s` → Save image  
- `p` → Save PDF  
- `c` → Clear screen  
- `d` → Draw mode  
- `m` → Mouse control mode  
- `n` → Navigation mode  

---

### 🎤 Voice Commands (if enabled)
- "draw" → Switch to drawing mode  
- "mouse" → Enable mouse control  
- "navigate" → Navigation mode  
- "save" → Save image  
- "pdf" → Export PDF  
- "clear" → Clear canvas  
- "stop" → Exit application  

---

### ✋ Gesture Controls (if enabled)
- fist → Navigation mode  
- open palm → Drawing mode  
- three fingers → Mouse mode  
- two fingers → Clear canvas  

---

⚠️ Note:
Laser detection works best in low-light conditions with a focused laser pointer.
